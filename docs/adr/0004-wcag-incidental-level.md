# WCAG gets an unofficial 1.5 "Incidental" level

WCAG 2 has no level below 3:1; everything under it fails. We still offer a 1.5 level, for huge display or marketing text and for inactive states. Its grade is "Incidental", WCAG's own term for text exempt from contrast rules (inactive UI, decoration), so it's clear this isn't a pass. APCA already has an equivalent low level (Spot, Lc 30), so the two methods stay parallel. Every other grade label uses the official WCAG 2 / APCA Bronze terms.
