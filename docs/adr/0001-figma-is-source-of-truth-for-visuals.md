# Figma is the source of truth for desktop visuals

The style guide was first written from MDS's reference repo, then the desktop design was drawn in Figma ([Colour Shift](https://www.figma.com/design/IFKpGTC3reLa2GWP6go6KH/Colour-Shift?node-id=0-1)). Where they differ, Figma wins and the style guide is updated to match. So tokens like `surface-raised` (`#262626`) and the 12px-row slider with a 24px grip come from Figma, not from MDS. Exception: contrast numbers in the mockups are illustrative only; the build always shows real scores.
